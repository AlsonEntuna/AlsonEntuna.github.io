Responsibilities

What I work on

Tools

Creating tools for multiple disciplines to aid art production. Using various languages and UI frameworks such as C++, C#, Python, Maxscript, QT, and WPF.

Worked with Maya, 3ds Max, Standalone Applications and CRYENGINE.

Pipeline

Aiding the TechArt and Art teams in creating pipelines for art production. Creating workflows for artists to become more efficient in their day to day tasks.

LODs

Implementing and developing LOD solution and tools using Simplygon API in different DCCs. Working together with the Engine team on various different topics to improve our LOD Solution in CRYENGINE.

CRYENGINE & plugins

Working inside the CRYENGINE source-code (C++) to add in more engine functionality, objects, and improvements. Communicating and collaborating with programmers to bring new features, bug fixes, and improvements to the current generation of CRYENGINE.

Roadmap planning

Planning ahead for the Technical Art team on what priorities we can to focus on for the year. Giving a brainstorming session for Seniors to think what we want to improve on the current year and plan out how we can execute the plans we planned and how we can tackle them if something arises that were not in our scope.

CRYENGINE team

Right now in 2024, we moved fully to the Engine team working on improving various different tools, features, editors, and plugins inside CRYENGINE.

I've been working inside the engine to provide more tools and improvements to the game teams on all projects in the company.

We've been very busy on understanding the engine and trying to produce plugins for our developers to make life easier in the Editor (Sandbox). Fully immersing ourselves in the engine's code base and refining the tools and giving it more love and much needed improvements.
